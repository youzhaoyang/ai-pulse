# Meshy Pro Plus / MAX 定价方案提案

为 Meshy 商业化 PM 课题准备的可交互原型 · 朝阳

## 内容

- **index.html** — 入口页
- **Pricing Modal.html** — In-App 升级弹窗版本（主推 · 还原 Meshy 当前 UI 风格）
- **Pricing.html** — 完整公开定价页（含定价计算器、定位象限图、对比表、FAQ）
- **pricing.css** / **pricing.js** — Pricing Page 的样式与交互

## 本地预览

直接用浏览器打开 `index.html` 即可，所有资源已就绪，无需构建。

## 部署

把整个文件夹的内容上传到任意静态托管即可（GitHub Pages、Cloudflare Pages、Vercel 等）。
